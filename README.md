# Lumbini Vana – villa VR walkthrough (proof of concept)

A walkable, baked-light VR tour of one Lumbini Vana villa: the 350 sq yd East-facing type (G+2, 4,478 sq ft), built
from the brochure plan. Made for a phone in a Cardboard-style headset with a Bluetooth remote (same delivery as
`C:\WORKPLACE\office-vr`), and also works by touch on a phone and with mouse + keys on a desktop. Static site, no build step.

## Run

```bash
python tools/serve.py            # http://127.0.0.1:8090   (add ?debug for fps / input overlay)
```

URL options: `?spot=Living` start in a room · `?mood=night` start at dusk · `?debug` · `?q=low|high` force phone/desktop quality ·
`?full` full-size lightmaps on a phone · `?noprobes` skip reflections · `?tm=1.15` exposure · `?ng=1.6` dusk exposure gain.

VR on a phone needs HTTPS: upload `web/` to any static HTTPS host (Render, Vercel, Netlify, GitHub Pages).

## Controls

| Input | Action |
|---|---|
| Head / drag | look (walking follows where you look) |
| Left stick, d-pad, WASD, arrows, on-screen joystick | walk: anywhere there is floor with headroom; walls, glass, furniture and plants stop you; stairs are walkable |
| Aim at a ring + A / Enter / Space / tap | move there (fade) |
| Remote B / R1, N, PageDown, volume up | next room (guided tour) |
| Remote X / L1, P, PageUp, volume down | previous room |
| Remote Y, L, the sun/moon button | day / evening light |
| Lift badges (G / 1 / 2) beside the lift door | ride the lift to another floor |
| Room chips at the bottom (no headset) | jump to a room |

## Pipeline

```
assets_src/  (CC0 Poly Haven textures, props, HDRI + generated textures)   tools/fetch_assets.py, tools/gen_textures.py
   │
blender/villa.py  ── the plan, in brochure pixels (refs/brochure/e350_*.jpg) ──►  build/villa.blend + build/layout.json
   │   uses blender/kit.py (materials, walls, doors, furniture, lights) and blender/lib.py (geometry, zones, nav data)
blender/bake.py   ── per zone: join, lightmap UVs, Cycles bake (day + dusk), OIDN ──►  build/light_*.npy, web/assets/zones/*.glb
tools/post.py     ── encode lightmaps (+ half size for phones), textures, sky ──►  web/assets/
web/              ── A-Frame viewer: js/villa.js (load, materials, reflection probes), js/nav.js (movement, rings, lift, HUD)
```

Rebuild everything (Blender 4.4 at its default path):

```bash
B="/c/Program Files/Blender Foundation/Blender 4.4/blender.exe"
python tools/fetch_assets.py && python tools/gen_textures.py          # once
"$B" -b -P blender/villa.py [-- --preview Living Aerial]              # build (+ Cycles previews in build/preview/)
"$B" -b build/villa.blend -P blender/navgrid.py                       # walkable floor computed from the geometry (~30 s)
"$B" -b build/villa.blend -P blender/check_plants.py                  # every plant clear of furniture and walls
"$B" -b build/villa.blend -P blender/bake.py [-- --quick]             # bake (--quick: 1024 px, ~90 s; full ~25 min)
python tools/post.py
python tools/hq.py                                                    # GPU-compressed KTX2: full-res lightmaps, 2K textures, relief maps (needs toktx)
node tools/walktest.mjs                                               # 10 keyboard walks: street to every floor, theatre, terrace, deck, lift
node tools/shoot.mjs Arrival Living                                   # headless screenshots (PW=<dir with playwright-core>)
```

## Changing the plan

All rooms, walls, openings and furniture positions in `blender/villa.py` are written in pixels of the enlarged brochure
plans (`refs/brochure/e350_gf.jpg`, `_ff`, `_sf`). `X(px)`, `Y(py)` convert to metres. When the exact architectural plan
arrives, update those numbers (and `SX`, `SY` if the scale differs), rebuild and re-bake.

## Budget

Download about 25–35 MB (Draco geometry, JPG lightmaps). Phones get 2048 px lightmaps. Floors two levels away from you
are not drawn. Check `?debug` on the phone for fps, draw calls and triangles.
